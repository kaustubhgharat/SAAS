Step 4: Create Validation Rules
________________________________________
STUDENT VALIDATIONS
1. Marks Between 0 and 100
Object:
Student__c
Validation Rule Formula:
OR(Marks__c < 0, Marks__c > 100)
Error Message:
Marks must be between 0 and 100
________________________________________
2. Roll Number > 0
Formula:
Roll_Number__c <= 0
Error:
Roll Number must be greater than 0
________________________________________
3. Email Must Contain @
Formula:
NOT(CONTAINS(Email__c, "@"))
Error:
Invalid Email Format
________________________________________
4. Student Name Cannot Be Blank
Formula:
ISBLANK(Std_Name__c)
Error:
Student Name cannot be blank
________________________________________
FACULTY VALIDATIONS
________________________________________
1. Faculty Name Minimum 3 Characters
Formula:
LEN(Faculty_Name__c) < 3
Error:
Faculty Name must contain at least 3 characters
________________________________________
2. Faculty ID > 0
Formula:
Faculty_ID__c <= 0
Error:
Faculty ID must be greater than 0
________________________________________
3. Salary Validation
Formula:
OR(Salary__c < 10000, Salary__c > 500000)
Error:
Salary must be between 10,000 and 500,000
________________________________________
4. Department Must Be Selected
Formula:
ISBLANK(TEXT(Department__c))
Error:
Please select Department
________________________________________
5. Joining Date Cannot Be Future Date
Formula:
Joining_Date__c > TODAY()
Error:
Joining Date cannot be future date
________________________________________
